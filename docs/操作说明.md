# Skyframe 787 · 操作说明

> 面向评审、讲解员与首次使用的观众。按本文顺序操作，可在 3 分钟内完成一次完整讲解。
> 所有操作均基于 `boeing/dist/index.html`（单文件离线版）。

---

## 1. 打开作品

### 1.1 推荐方式：直接双击离线文件

1. 确认文件为 `boeing/dist/index.html`；
2. 双击，浏览器地址栏以 `file:///` 开头；
3. 等待约 **3.5 秒**，启动遮罩淡出后进入三维场景。

### 1.2 本地服务器（开发 / 录屏）

```powershell
cd boeing
npm install      # 首次
npm run build
npm run serve    # http://localhost:8787/
```

### 1.3 在线体验

<https://summit05427.github.io/skyframe-787/>

> 不要直接打开 `src/index.html`，它是构建模板，页面是空的。

## 3. 基本视角操作

| 操作 | 鼠标 | 触摸 |
|---|---|---|
| 旋转 | 左键拖动 | 单指拖动 |
| 缩放 | 滚轮 | 双指捏合 |
| 平移 | 右键拖动 | 双指拖动 |

- 视角有阻尼，松手后会轻微滑行；点击「复位」（`R`）回到默认 3/4 机位。
- 相机距离限制 1.2–260；俯仰角不允许穿到地面以下。

## 4. 五种显示模式

点击顶栏模式胶囊，或按数字键：

| 键 | 模式 | 你会看到 | 适合讲什么 |
|---|---|---|---|
| `1` | 外观 | 涂装、舱门、舷窗、翼尖、发动机短舱 | 整机尺度与外形特征 |
| `2` | 透视 | 蒙皮变半透明青色，内部骨架、客舱、系统透出 | 内部结构与系统布置 |
| `3` | 剖视 | 蒙皮被剖切面切开，可切纵剖 / 俯剖 | 发动机内部、客舱分层 |
| `4` | 分解 | 8 个机身段 + 机翼/尾翼/发动机/起落架分离 | 总装分段与中央翼盒 |
| `5` | 材料 | 按材料着色 + 顶部图例与重量占比 | 复合材料 50% 的来源 |

### 4.1 剖视模式

- 模式胶囊下方出现「纵剖 / 俯剖」双段控件与「剖切位置」滑杆。
- 纵剖范围 `-3.4 ~ 31 m`，默认 `0`；俯剖范围 `1.2 ~ 8.2 m`，默认 `5.75`。
- 切换到另一种剖切轴会回到该轴的默认位置。

### 4.2 分解模式

- 「分解程度」滑杆 `0 ~ 100%`，默认 100%。
- 进入分解模式会自动把相机拉高、拉远；拖动滑杆时机体沿轴向展开。

### 4.3 材料模式

- 顶部显示 7 类材料图例与一条重量占比条（复合 50% · 铝 20% · 钛 15% · 钢 10% · 其他 5%）。
- 该模式下客舱与机载系统自动隐藏，避免遮挡结构材料。

## 5. 查看部件讲解

三种入口都能打开讲解（相机行为不同）：

1. **直接点飞机**：鼠标移到部件上会出现白色轮廓与名称提示；单击选中。
2. **点三维热点**：画面上带红色圆点的标签，点击即选中并飞近。
3. **用左侧部件树**：搜索框输入「襟翼 / APU / 舱门」等关键词，点击条目。

直接点飞机不会移动相机；点三维热点或部件树会飞近该部件（约 1.25 s）。

选中后：

- 机体上出现**猩红描边**；
- 右侧信息卡显示：分组、中文名、英文名、说明、关键参数、「你知道吗」、模型实例数；
- 若该部件属于被关闭的图层，会自动打开；
- 从部件树选择内部件、且当前是外观模式时，会自动切到透视模式（在 3D 画面直接点选不会自动切）。

右侧三个操作：

| 按钮 | 作用 |
|---|---|
| 聚焦 | 相机飞到该部件（约 1.25 s） |
| 单独显示 | 只保留该部件，其余隐藏；再次点击恢复 |
| 透视查看 | 仅外观模式下出现，切到透视并保持选中 |

取消选择：点画面空白、按 `Esc`，或点信息卡右上角 `×`。

## 6. 底部控制台

### 6.1 飞行操纵

| 控件 | 范围 | 默认 | 说明 |
|---|---|---|---|
| 襟翼手柄 | 0–9 档 | 0（收上） | 对应 0/1/5/10/15/17/18/20/25/30° |
| 减速板 / 扰流板 | 0–100% | 0 | 落地后竖起破坏升力 |
| 滚转（副翼） | -100% ~ +100% | 0 | 左 / 右 |
| 俯仰（升降舵） | -100% ~ +100% | 0 | 低头 / 抬头 |
| 偏航（方向舵） | -100% ~ +100% | 0 | 左 / 右 |
| 平尾配平 | -5° ~ +5° | 0 | 整体偏转水平安定面 |

「舵面回中」一键把滚转、俯仰、偏航、配平、减速板归零。

### 6.2 动画与灯光

| 开关 | 默认 | 效果 |
|---|---|---|
| 起落架 | 放下 | 舱门开 → 支柱摆动 → 舱门关，全程约 6.5 s |
| 发动机 | 停车 | 风扇与核心机转子加速，约 3.3 s 到稳态 |
| 反推 | 收起 | 短舱平移罩后移、叶栅露出，约 1.4 s |
| 冲压空气涡轮 | 收起 | 机腹 RAT 伸出并旋转 |
| 飞行状态 | 地面 | 收起落架、机翼上挠、隐藏地面与引导线 |
| 防撞灯 / 频闪灯 / 航行灯 / 着陆灯 | 防撞灯与航行灯开 | 控制对应灯光闪烁 |

### 6.3 显示

| 控件 | 默认 | 说明 |
|---|---|---|
| 图层：蒙皮外形 / 内部结构 / 客舱货舱 / 机载系统 / 起落架 | 全开 | 单独关闭某一层 |
| 部件标注 | 开 | 显示三维热点标签 |
| 尺寸标注 | 关 | 显示机长、翼展、机高、轮距等尺寸线 |
| 舷窗调光 | 80% | 0% 透明，100% 最暗 |

## 7. 16 步导览

点击右上角「导览」或按 `T` 开始；`←` / `→` 切换；按 `T`、点导览卡右上角 `×` 或走完第 16 步退出（`Esc` 只取消选中，不退出导览）。

| # | 标题 | 看点 |
|---|---|---|
| 01 | 认识波音 787-9 | 整机尺度、两舱 290 座、约 14,000 km 航程 |
| 02 | 一半是复合材料 | 材料模式与 50% 复合材料的构成 |
| 03 | 像搭积木一样总装 | 分解模式下的 41/43/44/46/47/48 段 |
| 04 | 机头与驾驶舱 | 雷达罩、4 块风挡、前设备舱 |
| 05 | 会「弯」的机翼 | 飞行状态下的机翼上挠 |
| 06 | 起降时的「变形」：增升装置 | 缝翼、襟翼、襟副翼 |
| 07 | 扰流板与飞行舵面 | 7 块扰流板与副翼/升降舵/方向舵 |
| 08 | 剖开发动机 | 剖视下的 GEnx-1B 核心机 |
| 09 | 反推：让推力向前吹 | 平移罩与叶栅 |
| 10 | 起落架 | 每 8 秒自动收放的循环演示 |
| 11 | 机身骨架 | 隔框、长桁、地板梁 |
| 12 | 客舱与货舱 | 中线剖开后的座椅与 LD3 |
| 13 | 多电飞机 | 电源馈线、空调压缩机、液压 |
| 14 | 燃油装在哪里 | 中央油箱与左右主油箱 |
| 15 | 尾部：尾翼与 APU | 后压力隔框、可配平平尾、尾锥 APU |
| 16 | 自由探索 | 回到外观模式，交还操作 |

导览会自动切换模式、图层、选中部件与机位；每步相机飞行 1.7 s。导览期间左栏与折叠抓手隐藏，右侧信息卡仅在无选中时隐藏（该步有选中部件时仍显示详情），导览卡固定在底部。

## 8. 主题与语言

- **环境光照**：顶栏「影棚 / 日光」双段控件。日光会同时改变天空、雾、地面、环境贴图、曝光与尺寸线颜色。
- **界面语言**：顶栏「中 / EN」。切换只重渲染文案层，不重建模型，不丢失当前选中与导览进度。
- 也可用 URL 直接指定语言：`dist/index.html?lang=en`。

---

## 9. 标注与尺寸

- 顶栏标签图标或 `L`：开关三维热点标签。外观模式只显示外部热点；透视/剖视会显示内部热点。
- 顶栏尺子图标：开关尺寸线；开启时会切到适合看全机的机位。按 `D` 只开关尺寸线，不移动相机。
- 热点会按优先级避让，选中部件的标签永远显示；剖视下只标注真正被剖开露出的部件。

## 10. 面板折叠

| 面板 | 操作 | 收起后 |
|---|---|---|
| 左侧部件面板 | 点面板右缘抓手 | 滑出画面，抓手贴左边缘 |
| 右侧信息面板 | 点面板左缘抓手 | 隐藏，抓手贴右边缘 |
| 底部控制台 | 点控制台上方横条抓手 | 下滑隐藏，仅留横条 |

折叠后相机投影中心会自动重新计算，画面构图随之平移；再次展开恢复。窄屏（≤1180）左栏改为抽屉，由左上角列表按钮开合。

## 12. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 打开后一直停在「正在以程序化方式生成整机几何…」 | WebGL2 不可用 / 硬件加速关闭 / 显卡驱动异常 | 换 Chrome 或 Edge，开启硬件加速；确认不是极旧设备 |
| 页面空白 | 打开了 `src/index.html` 模板 | 改用 `dist/index.html` |
| 画面卡顿 | 1080p + 核显 + 高 DPR | 降低窗口分辨率或系统缩放；关闭其他标签页 |
| 点不中内部部件 | 当前是外观模式 | 按 `2` 切透视，或从部件树选择 |
| 折叠面板后构图偏了 | 相机投影中心随可用区域重算，属预期行为 | 按 `R` 复位 |
| 中英切换后仍显示中文 | 浏览器缓存旧构建 | `Ctrl + F5` 强刷；或重新 `npm run build` |
| `file://` 下语言不记忆 | 隐私模式 / 本地存储受限 | 直接用 `?lang=en` 指定 |
