# Skyframe 787 · 交互控件索引

> 供测试、录屏脚本与评审复现使用。ID 均可在 `src/main.js` 的界面模板与事件绑定中检索；数值为代码中的真实范围与默认值。

---

## 1. 快捷键

| 按键 | 作用 | 生效条件 |
|---|---|---|
| `1` | 外观 | 非文本输入框聚焦 |
| `2` | 透视 | 同上 |
| `3` | 剖视 | 同上 |
| `4` | 分解 | 同上 |
| `5` | 材料 | 同上 |
| `G` | 起落架收 / 放 | 同上 |
| `F` / `Shift + F` | 襟翼放下一档 / 收回一档 | 同上 |
| `B` | 减速板开 / 关 | 同上 |
| `E` | 发动机运转 / 停车 | 同上 |
| `V` | 反推开 / 关 | 同上 |
| `L` | 标注开关 | 同上 |
| `D` | 尺寸开关 | 同上 |
| `T` | 开始 / 退出导览 | 同上 |
| `←` / `→` | 导览上一步 / 下一步 | 仅导览中 |
| `R` | 复位视角 | 同上 |
| `?` 或 `/` | 开关帮助 | 同上 |
| `Esc` | 关闭帮助 → 取消选择 | 同上；搜索框聚焦时先失焦 |

> 组合键（Ctrl / Cmd / Alt）按下时不触发任何快捷键；文本输入框内除 `Esc` 外不响应。

## 3. 模式附加条 `#modebar`

| 控件 | ID / 选择器 | 类型 | 范围 / 默认 | 作用 |
|---|---|---|---|---|
| 剖切轴 | `[data-axis="z"]` / `[data-axis="y"]` | 双段 ×2 | `z` | 纵剖 / 俯剖；切换后回到该轴默认位置 |

## 8. 机构变化速率与稳定时间

| 量 | 速率（每秒） | 0 → 满行程耗时 |
|---|---|---|
| `flaps` 襟翼 | 7°/s | 30° 约 **4.3 s** |
| `speedbrake` 减速板 | 1.6 | **0.63 s** |
| `roll` / `pitch` / `yaw` | 3.5 | **0.29 s** |
| `trim` 平尾配平 | 1.2 | **0.83 s** |
| `gear` 起落架 | 1/6.5 | **6.5 s** |
| `reverser` 反推 | 0.7 | **1.43 s** |
| `n1` 发动机 | 0.3 | **3.33 s** |
| `rat` 冲压空气涡轮 | 0.6 | **1.67 s** |
| `flex` 机翼上挠 | 0.45 | **2.22 s** |
| `explode` 分解 | 0.9 | **1.11 s** |
| 透视 uniform | 每帧 7×dt 收敛 | 约 **0.5 s** |

其他节奏：

- 防撞灯周期 1.25 s，亮 0.11 s；频闪灯周期 1.1 s，双闪；着陆灯常亮。
- 导览「起落架」步骤每 **8 s** 自动在两个状态间往返。
- 相机飞行：常规 **1.25 s**，导览 **1.7 s**。

## 9. 浏览器权限 API

| API | 是否使用 | 触发点 | 说明 |
|---|---|---|---|
| WebGL2 | **是（能力要求）** | 应用启动 | 不是权限弹窗；不可用则无法进入 |
| `localStorage` | **是** | 语言切换 | 仅 `skyframe.locale` |
| History API | **是** | 语言切换 | `history.replaceState` 同步 `?lang=` |
| 摄像头 `getUserMedia` | 否 | — | 不请求 |
| 麦克风 | 否 | — | 不请求 |
| 指针锁定 `requestPointerLock` | 否 | — | 不使用 |
| 全屏 `requestFullscreen` | 否 | — | 无全屏按钮；可用浏览器 F11 |
| 地理定位 / 剪贴板 / 通知 | 否 | — | 不使用 |
| 网络请求 | 否 | — | 运行时零外部请求 |

## 10. 会触发相机飞行 / 画面移动的控件

| 入口 | 触发条件 | 目标 | 时长 |
|---|---|---|---|
| `#tree .item` | 点击部件行 | 该部件包围球 | **1.25 s** |
| `.hs` 三维热点 | 点击热点 | 该部件包围球 | **1.25 s** |
| `#act-focus` | 点击「聚焦」 | 当前部件 | **1.25 s** |
| `#act-iso` | 开启「单独显示」 | 当前部件 | **1.25 s** |
| `#btn-dims` | 点击按钮开启尺寸 | 整机尺寸机位 | **1.25 s** |
| `D` | 按键开关尺寸 | **不移动相机** | — |
| `#btn-home` / `R` | 点击 / 按键 | 默认 3/4 机位 | **1.25 s** |
| 模式切到「分解」 | 非导览时 | 分解整机机位 | **1.25 s** |
| 导览每一步 | `T` / `→` / 进度点 | 该步预设机位 | **1.7 s** |
| 窗口 resize | 自动 | 重新计算投影偏移 | 立即 |
| 折叠 / 展开面板 | 自动 | 重新计算投影偏移 | 立即（CSS 0.24 s） |
| 3D 画布单击 | 选中部件 | **不移动相机** | — |
| 信息卡关闭 / `Esc` | 取消选择 | **不移动相机** | — |

> 录屏时若要稳定构图，避免在关键镜头中点击部件树、三维热点、「聚焦」「单独显示」「尺寸」与导览跳转；这些都会移动相机。需要「选中但不移动」时，直接在 3D 画面上单击部件。

## 11. 调试出口

浏览器控制台可直接调用：

```js
window.__app.S                 // 全局状态
window.__app.setMode('xray')   // 切模式
window.__app.select('wingBox') // 选中部件（不飞行）
window.__app.flyTo([-60,20,60,-1,5,0], 1.2)
window.__app.tourGo(12)        // 跳到第 13 步
window.__app.aircraft.tgt      // 机构目标值
window.__app.stage.renderer.info.render  // 渲染统计
window.__errors                // 启动时收集的运行时错误
```
