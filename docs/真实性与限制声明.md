# Skyframe 787 · 真实性与限制声明

> 一句话：本作品是**科普演示与交互设计作品**，不是官方工程软件，也不是维修/训练资料。所有数值、结构与机构动作按公开资料与示意动画制作，并按 A–D 分级标注。

| 等级 | 名称 | 含义 | 本作品中的典型内容 |

## 2. 哪些是官方数据（A）

- 787-9 的三维尺寸、最大起飞重量、典型座位数、航程、巡航速度、发动机型号与首次交付年份。
- 舱门数量与门位（距机头 6.30 / 18.36 / 35.43 / 49.66 m）、货舱门净开口、散货舱门位置。
- 起落架布置：前起落架 2 轮、主起落架每侧 4 轮；主轮距 9.80 m、前主轮距 25.83 m。
- 机体材料重量占比：复合材料约 50%、铝 20%、钛 15%、钢 10%、其他 5%。
- 公开的系统事实：取消发动机引气、每台发动机两台 250 kVA 起动发电机、APU 两台发电机、总发电约 1.45 MW、三套 5,000 psi 液压、燃油约 12.6 万升、36 个 LD3 集装箱位、舷窗约 27×47 cm。
- 机身段供应商：Spirit AeroSystems、川崎重工、Leonardo、波音南卡罗来纳、三菱重工、大韩航空航宇、哈飞、成飞、沈飞、Latécoère、Saab 等公开信息。

上述内容以波音《787 Airplane Characteristics for Airport Planning》、EASA/FAA 型号合格证数据单及制造商公开资料为准。

## 3. 哪些是科普示意（B / C）

- 机身内部隔框、长桁、地板梁的数量、间距与截面形状；
- 客舱 28 公务 + 262 经济的示例布局、厨房/盥洗室/机组休息室位置；
- 系统管路的具体走向、颜色与设备安装位置；
- 燃油箱边界、通气油箱位置与惰化系统示意；
- 发动机核心机级数、叶片数量与内部结构；
- 涂装、标识、面板分缝与检修口盖；
- 三维热点的锚点位置与避让规则；
- 材料类别到每个零件的具体映射（部分零件为合理推断）。

这些内容用于解释「关系与原理」，不作为工程复现依据。

## 4. 哪些是纯动画模拟（D）

- 机翼在飞行状态下的上挠（`flex`）；
- 起落架收放与舱门时序（前起向前、主起向内，全程 6.5 s）；
- 反推平移罩与叶栅开合；
- 襟翼十档、缝翼密封位/开缝位、襟副翼、副翼、扰流板、升降舵、方向舵、平尾配平；
- 冲压空气涡轮伸出与旋转；
- 发动机 N1/N2 转子转动（非真实转速）；
- 防撞灯、频闪灯、航行灯、着陆灯的闪烁节奏；
- 剖切面移动、分解位移、透视过渡、相机飞行。

全部为交互动画，**不构成结构力学、飞行动力学、系统仿真或维修时序**。

## 6. 性能与兼容限制

| 项 | 限制 |
|---|---|
| 图形 | 必须支持 WebGL2 并开启硬件加速；**无降级页**，不可用时停在启动遮罩 |

## 7. 内容与工程限制

1. **113 条部件不是全部零件**：优先覆盖可讲解、可观察的结构与系统；管路、线束、紧固件大量简化。
2. **几何为程序化近似**：曲面、翼型、整流罩与真实外形存在偏差，不能用于测量。
3. **英文文案未母语审校**：术语与句式可能不地道，但保持与中文一一对应。
4. **断点未逐一截图验证**：`1340 / 1180 / 900 / 820` 主要靠 CSS 推演。
5. **无自动化测试**：没有 ESLint / Prettier / 单测 / Playwright；回归依赖人工。
6. **`src/main.js` 仍为单体**：UI、拾取、导览、控制台混在一处，后续扩展前建议拆分。
7. **无 LICENSE 文件**：`package.json` 声明 ISC，但仓库根目录尚无许可证文本；参赛或开源前需补齐。
8. **无导出功能**：不能导出图片、模型或参数表。
