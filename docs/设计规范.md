# Skyframe 787 · 设计规范

> 适用范围：`boeing/src/styles.css`、`boeing/src/main.js` 中的 UI 模板与 3D 视觉参数。
> 原则：**暗黑高级 + 猩红强调**。红色只做「当前状态」与「主操作」，其余一律中性灰；三维画面优先，界面永远退后一层。

---

## 1. 设计基调

| 关键词 | 落地方式 |
|---|---|
| 航空仪表感 | 等宽数字、全大写小字距 kicker、发丝描边、深色玻璃面板 |
| 克制 | 80/20 用色：红色面积不超过界面 20% |
| 层次 | 三级文字（主/次/弱），面板 86% 不透明 + 20px 背景模糊 |
| 画面优先 | 顶栏与面板均为浮层；折叠后只留边缘抓手，把画面还给模型 |
| 双语 | 中文为主、英文副标题；所有文案走 `t()`，不硬编码 |

### 2.2 红色 80/20 规则

**允许用红**：

- 主操作按钮（顶栏「导览」CTA、信息卡「开始导览」等唯一主按钮）
- 当前模式 / 当前 Tab 的 2px 底边指示线
- 滑块已滑过段、拇指描边与辉光、到顶数值
- 列表选中项左侧 3px 竖条
- 三维热点圆点、引线、选中热点底
- 参数极值（滑杆拉满）与尺寸标注胶囊
- 启动进度条、toast/提示卡描边

**禁止用红**：正文、表格、面板大面积背景、非当前态的图标、装饰性渐变。

## 3. 字体

| 角色 | 字体栈 | 用法 |
|---|---|---|
| 无衬线 | `Bahnschrift / DIN Alternate / PingFang SC / Microsoft YaHei UI / Microsoft YaHei / Noto Sans SC` | 全部界面文字 |
| 等宽 | `Cascadia Mono / Cascadia Code / SF Mono / JetBrains Mono / Consolas` | 数字、代号、状态值、步骤号、参数值 |

| 层级 | 字号 / 行高 | 字重 | 示例 |
|---|---|---|---|
| 页面基准 | 13px / 1.55 | 400 | 正文、列表 |
| 信息卡标题 h2 | 21px / 1.3 | 600 | 部件名 |
| 导览标题 h3 | 18px / 1.3 | 600 | 导览步骤名 |
| 模式胶囊 | 12.5px | 500（当前 600） | 外观 / 透视… |
| 顶栏小字 | 11–12px，字距 .04–.14em | 500–600 | kicker、标签 |
| 步骤号 | 20px 等宽 | 600 | `01 / 16` |
| 参数值 | 12px 等宽 | 400 | `30°`、`62.81 m` |

约束：

- 中文标题不用斜体；英文副标题用等宽、`--tx3`，形成「主名 + 机读副名」的层级。
- 数字统一等宽并启用 `font-variant-numeric: tabular-nums`，避免滑块拖动时抖动。
- 英文界面（`body[data-locale="en"]`）模式按钮收紧内边距与字距，防止溢出。

## 5. 组件规范

### 5.1 模式胶囊

- 容器：玻璃底 + 1px 描边 + 全圆角，内边距 3px，按钮间距 2px。
- 默认：`--tx2` 文字、透明底。
- 悬停：`--tx` + `--bg2` 底。
- 当前：纯白文字 + 600 字重 + 底边 16×2px 猩红短线；**不使用红色填充块**。

### 5.2 顶栏工具按钮

- 34×34 最小尺寸，圆角 10px，玻璃底 + 发丝描边。
- 图标 16px；导览 CTA 为猩红实心 + 白字，图标 19px。
- 开启态（标注/尺寸）：`--acc-text` 文字 + `--acc-line` 描边 + 透明底。
- 双段控件（主题 / 语言）：容器 3px 内边距，当前段 `rgba(255,255,255,.13)` 底 + 白字。

### 5.3 左侧部件树

- 分组用 `<details>`；分组行 7px 竖向内边距，色块 8×8px，右侧计数用等宽小字。
- 部件行：左缩进 22px，圆角 7px；中文名 + 英文小字（等宽 10.5px）。
- 选中：`rgba(255,255,255,.06)` 底 + 左侧 3px 猩红竖条 + 白字。
- 搜索框：32px 高，深色内凹底；聚焦时红色描边。

### 5.4 右侧信息卡

- 顶部 kicker：色块 + 分组名（大写、字距 .14em）+ 右上关闭 `×`。
- 标题中文 21px，英文副标题等宽 11.5px。
- 参数表：每行上下 6px、1px 分隔线，键左值右；总览页用两列网格。
- 「你知道吗」提示卡：中性深灰底 + 1px 描边；仅灯泡图标与标题用 `--acc-text`。
- 操作区：等宽三按钮（聚焦 / 单独显示 / 透视查看），32px 高。
- 底部实例数用等宽 11px `--tx3`。

### 5.5 滑块

- 两行结构：上行「标签 + 数值」，下行轨道；三列并排不挤。
- 轨道高 3px：未滑过 `#333`，已滑过 `--acc`；用 `--p` 变量画进度。
- 拇指：13px 白色圆点 + 2px 猩红描边 + 10px 红色辉光；按下放大 1.12。
- 数值默认 `#D6D6D6`；**只有到达最大值**才转 `--acc-text`（`output.ext`）。
- 宽版（剖切/分解）为三列：标签 | 轨道 | 数值，最小宽 400px（≤1180 时 260px）。

### 5.6 开关

- 高 30px，圆角 8px，`--bg2` 底 + 发丝描边。
- 左侧 7px 状态点：关闭 `--tx3`，开启 `--acc-text` + 6px 红色辉光。
- 可选状态文案（放下/收上、运转/停车）用等宽 11px `--tx3`。

### 5.7 折叠抓手

- 侧边：18×56px，贴面板外缘；收起后贴窗口边缘 8px，图标旋转 180°。
- 底部：56×18px，位于控制台正中上方；收起后图标旋转，控制台下滑 `translateY(100% + 24px)` 并淡出。
- 抓手是唯一常驻的「面板存在感」，因此保持低对比（`--tx3`），悬停才转红。

### 5.8 导览卡

- 玻璃底 + 红色描边；标题行含 `01 / 16` 步骤号（红色等宽）。
- 正文 13.5px / 1.8，两端对齐；底部为进度点 + 上一步 + 下一步/完成。
- 进度点：4px 高，已完成 `--acc-line`，当前 `--acc`，未到 `--bg3`，可点击跳转。
- 导览中隐藏左栏、折叠抓手；右侧信息卡仅在无选中时隐藏（`body.touring:not(.has-sel)`），避免抢占画面。

### 5.9 三维热点与尺寸标注

- 热点：8px 猩红圆点 + 3px 淡红光晕 + 1px 深色描边；上方 13px 红色引线；标签为深色玻璃底 + 红色描边。
- 悬停：标签转淡红底红字；选中：标签转猩红实心白字。
- 热点按优先级避让，选中项永远优先显示；剖视下只显示真正被剖开露出的内部件。
- 尺寸标注：1px 红线 + 端部短线；标签为猩红胶囊白字等宽 12px。

### 5.10 浮层

- 悬停提示 `#tip`：跟随指针，最多距右边缘 220px；两行（中文名 + 英文名）。
- Toast：顶部居中胶囊，2.6 s 自动消失；无模式附加条时上移到 72px。
- 帮助：全屏 62% 黑遮罩 + 2px 背景模糊，卡片内 15 组快捷键两列排布。

## 6. 动效

| 场景 | 时长 / 曲线 |
|---|---|
| 悬停 / 选中态 | 0.14–0.16s `ease` |
| 面板滑出 / 控制台收起 | 0.24s `ease` |
| 启动遮罩淡出 | 0.6s；700ms 后移除节点 |
| 热点出现 | 0.22s `ease-out` 淡入 |
| 相机飞行 | 1.25s（常规）/ 1.7s（导览），smootherstep 缓动 |
| 透视过渡 | 每帧向目标值收敛 7×dt，约 0.5s 稳定 |
| 机构动作 | 由 `aircraft/index.js` 的 `rate` 决定：襟翼 7°/s、起落架 6.5s 全程、反推 1.4s、发动机 3.3s、机翼上挠 2.2s、分解 1.1s |

无障碍：

- 尊重 `prefers-reduced-motion: reduce`：关闭全部 CSS 动画与过渡。
- 焦点可见：`outline: 2px solid var(--acc-text)`，偏移 2px。
- 双段控件使用 `aria-pressed`；折叠抓手使用 `aria-expanded` 与 `aria-controls`。

## 7. 响应式

| 断点 | 变化 |
|---|---|
| `≤1340px` | 隐藏标注、尺寸、复位三个次要工具，避免与居中模式胶囊重叠 |
| `≤1180px` | 顶栏改为 flex 流式；左栏变抽屉（左上角列表按钮开合）；控件网格 2 列 |
| `≤900px` | 压缩模式胶囊内边距与字号；模式附加条上移 |
| `≤820px` | 隐藏主题切换；右侧信息面板改为底部浮层（仅选中时出现）；底部控制台默认收起；控件网格 1 列；帮助卡单列 |
| `prefers-reduced-motion` | 关闭动画 |

> `layoutView()` 的相机留白常量（左 264 / 右 340）跟随面板显隐计算；窗口 resize 与面板折叠都会重新取景，但不会拉伸画布。

## 8. 三维视觉语言

- **默认机位**：右前上方 3/4 视角，目标点 `(-1, 5, 0)`，机头朝 -x、左翼朝 +z。
- **主光**：暖白平行光（`#FFF3E2`，强度 3.0）自右上方；补光冷蓝（`#9DB8E8`，0.55）；半球光 0.55。
- **环境**：程序化 PMREM 天光 + 四个柔光箱，不使用 HDR 文件。
- **描边**：选中猩红 `#FF5A6A`（强度 4.5、辉光 0.35、厚度 1.6）；悬停白 `#FFFFFF`（强度 2.6）。透视/剖视下隐藏边的描边保留 100%，其余模式降到 12%，避免对侧对称件抢眼。
- **地面**：1600×1600 程序化混凝土网格，每 10m 一格、5m 细分；飞行状态隐藏地面与引导线。
- **构图**：所有导览机位按 16:9 编排；可用区域更窄时按 `1.62 / freeAspect` 等比拉远，上限 2.4 倍。

## 9. 文案规范

- 中文优先：默认 `zh`，英文为副标题或切换态。
- 术语统一：`分解`（不写「爆炸」）、`剖视`（不写「剖面」）、`透视`、`外观`、`材料`、`导览`。
- 按钮用动词或名词短语，不超过 6 个汉字；英文不超过 14 个字符。
- 参数写法：数值 + 空格 + 单位（`62.81 m`、`290 座`、`马赫 0.85`）。
- 免责声明固定句式见 [真实性与限制声明.md](真实性与限制声明.md)。
