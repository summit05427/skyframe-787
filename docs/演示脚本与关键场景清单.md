# Skyframe 787 · 演示脚本与关键场景清单

> 用途：2 分钟参赛视频分镜、评审现场演示、高保真设计图截屏。
> 每个场景写清四件事：**进入前提 → 操作序列 → 动画稳定等待 → 期望画面**。
> 时间基于本机实测（Chrome 158 / Intel UHD / 1600×900）与代码中的动画速率；独显可略快。

---

## 0. 通用约定

| 项 | 值 |
|---|---|
| 入口 | `boeing/dist/index.html` |
| 首屏等待 | 打开后 **4.5 s**（遮罩完全移除约 3.5 s，再留 1 s 保险） |
| 默认模式 | 外观 `ext` |
| 默认状态 | 标注开、尺寸关、面板全开、控制台「飞行操纵」、影棚主题、中文 |
| 相机飞行 | 常规 1.25 s；导览 1.7 s；缓动为 smootherstep |
| 机构稳定 | 襟翼 0→30° 约 4.3 s；起落架 6.5 s；反推 1.4 s；发动机 3.3 s；机翼上挠 2.2 s；分解 1.1 s；减速板 0.6 s |
| 透视过渡 | 约 0.5 s |
| 录屏建议 | 1920×1080 / 30fps / 系统缩放 100%；每次相机飞行后多等 0.5 s |

> **不要在关键镜头中点击部件树或三维热点**：两者都会让相机飞向部件（1.25 s）。若只想选中不移动，直接在 3D 画面上单击部件。

## 1. 关键场景

### S1 · 首屏与外观总览

| 项 | 内容 |
|---|---|
| 进入前提 | 打开 `dist/index.html`，不按任何键 |
| 操作序列 | 无；可轻微左键拖动 5° 增加动感 |
| 稳定等待 | **4.5 s**（遮罩消失后再等 0.5 s） |
| 期望画面 | 右前上方 3/4 全机；白色机身 + 深蓝尾翼；红色热点标签分布机头、舱门、翼尖、发动机、起落架；左侧 113 部件树；右侧总览规格表；底部飞行操纵滑杆；顶栏模式胶囊停在「外观」 |

### S2 · 透视看内部

| 项 | 内容 |
|---|---|
| 进入前提 | 外观模式，无选中 |
| 操作序列 | 按 `2` 或点「透视」 |
| 稳定等待 | **0.8 s** |
| 期望画面 | 蒙皮变为半透明青蓝，边缘发光；隔框、长桁、地板梁、客舱座椅、系统管路透出；模式胶囊「透视」带猩红底线；无模式附加条；内部热点由 1 级切到 2 级 |

### S3 · 剖视发动机

| 项 | 内容 |
|---|---|
| 进入前提 | 任意模式 |
| 操作序列 | 按 `3` → 确认「纵剖」→ 把「剖切位置」拖到约 **9.9 m** → 在 3D 画面单击左发动机核心机（或搜索 `engHPC` 后点树，注意会飞行 1.25 s） |
| 稳定等待 | 滑块即时；相机飞行 **1.4 s**；再等 0.5 s |
| 期望画面 | 短舱与核心机被纵向切开，可见风扇、增压级、高压压气机、燃烧室、涡轮；右侧信息卡显示发动机部件参数；剖切面外侧的蒙皮被裁掉 |

### S4 · 分解总装

| 项 | 内容 |
|---|---|
| 进入前提 | 外观或透视 |
| 操作序列 | 按 `4` → 相机自动复位 → 把「分解程度」从 100% 拖到 0% 再拖回 100% |
| 稳定等待 | 进入模式 **1.4 s**；滑块全程 **1.2 s** |
| 期望画面 | 41/43/44/46/47/48 段与尾锥沿机身轴分离；机翼向左右、发动机向斜下、尾翼向上、起落架向下分离；中央翼盒下移；相机拉高俯视 |

### S5 · 材料比例

| 项 | 内容 |
|---|---|
| 进入前提 | 外观模式 |
| 操作序列 | 按 `5` |
| 稳定等待 | **0.5 s** |
| 期望画面 | 机体按 7 类材料着色：机身/机翼/尾翼蓝青（复合材料）、前缘黄（铝）、吊挂与起落架附近橙/粉（钛/钢）；顶部出现图例与「复合 50% · 铝 20% · 钛 15% · 钢 10% · 其他 5%」占比条；客舱与系统隐藏 |

### S6 · 点选部件与讲解卡

| 项 | 内容 |
|---|---|
| 进入前提 | 外观模式 |
| 操作序列 | A. 3D 单击机翼中段（不飞行）<br>B. 或左侧搜索「襟翼」→ 点击条目（飞行 1.25 s） |
| 稳定等待 | A **0.3 s**；B **1.5 s** |
| 期望画面 | 选中部件猩红描边；右侧卡出现分组色块、中文名、英文副标题、说明、参数表、「你知道吗」、实例数；底部出现「聚焦 / 单独显示」；树中对应行高亮并滚动到可见 |
| 注意 | 从部件树选择内部件且当前是外观模式时，会自动切透视，画面会变一次；3D 直接点选不会自动切 |

### S7 · 增升装置与扰流板

| 项 | 内容 |
|---|---|
| 进入前提 | 外观模式，底部控制台在「飞行操纵」 |
| 操作序列 | 把「襟翼手柄」从「收上」拖到 **30**（或按 `F` 九次）→ 把「减速板 / 扰流板」拖到 **100%**（或按 `B`）→ 建议按 `R` 后先拖视角到左前方看机翼 |
| 稳定等待 | 襟翼 **4.5 s**；减速板 **0.8 s** |
| 期望画面 | 前缘缝翼向前下方伸出、后缘襟翼下垂、襟副翼随动；上表面 7 块扰流板竖起；数值在满行程时转红 |

### S8 · 起落架收放

| 项 | 内容 |
|---|---|
| 进入前提 | 外观模式；建议先按 `R` 回到整机 |
| 操作序列 | 底部「动画与灯光」→ 点「起落架」开关；或直接按 `G` |
| 稳定等待 | **6.8 s**（完整一个方向） |
| 期望画面 | 舱门先打开 → 前起落架向前、主起落架向内收入机腹 → 舱门关闭；开关状态文字在「放下 / 收上」间切换；机腹轮舱可见 |

### S9 · 16 步导览

| 项 | 内容 |
|---|---|
| 进入前提 | 任意状态 |
| 操作序列 | 按 `T` 或点右上「导览」→ 每步按 `→` 或点「下一步」；至少演示 01 → 02 → 03 → 08 → 13 |
| 稳定等待 | 每步 **2.2 s**（相机 1.7 s + 0.5 s） |
| 期望画面 | 左栏与折叠抓手隐藏；右侧信息卡随该步是否选中而显隐；底部导览卡显示 `01 / 16`、标题、正文、进度点；每一步自动切模式/图层/选中；第 1 步「上一步」禁用；第 16 步按钮变「完成」 |
| 退出 | `T`、点导览卡 `×` 或「完成」；`Esc` 只取消选中，不退出导览 |

### S10 · 中英双语与主题

| 项 | 内容 |
|---|---|
| 进入前提 | 任意状态 |
| 操作序列 | 点顶栏「EN」→ 再点「日光」→ 再切回「中」与「影棚」 |
| 稳定等待 | 语言 **0.2 s**；主题 **0.6 s** |
| 期望画面 | 全部界面、部件名、讲解、导览、图例切英文，模型不重建、选中不丢失；日光下天空变蓝、地面变浅、曝光降低、尺寸线转深红；Toast 提示「日光环境 / Daylight environment」 |

### S11 · 面板折叠与构图回收

| 项 | 内容 |
|---|---|
| 进入前提 | 桌面端 ≥1180px |
| 操作序列 | 依次点左面板右缘抓手、右面板左缘抓手、控制台上方横条 |
| 稳定等待 | **0.4 s** |
| 期望画面 | 左/右面板滑出，抓手贴边并翻转；控制台下滑，仅留横条；相机投影中心随之平移，飞机仍位于可见区域中央，画布无拉伸、无黑边 |

## 4. 现场演示 3 分钟口播流程

1. **0:00–0:20** 打开 `dist/index.html`，等首屏；说明「单文件、离线、零后端」。
2. **0:20–0:50** `2` 透视 → 点机身隔框 → 讲半硬壳结构；`Esc` 取消。
3. **0:50–1:20** `3` 剖视 → 拖到发动机 → 讲核心机；`1` 回外观。
4. **1:20–1:50** `4` 分解 → 讲 41/43/44/46/47/48 段与中央翼盒；`5` 材料 → 讲 50% 复合。
5. **1:50–2:20** 底栏襟翼 30 + 扰流板 → 讲增升与减升；`G` 收起落架。
6. **2:20–2:45** `T` 导览跳到「多电飞机」→ 讲无引气架构。
7. **2:45–3:00** `Esc` 退出导览 → `R` 复位 → 切 EN 展示双语 → 回到作品名与定位。

> 每个动作之间留 2 s，让相机飞行与机构动画完成；不要连续快速点击。

## 5. 演示失败兜底

| 风险 | 兜底 |
|---|---|
| 现场机器无 WebGL2 | 提前准备录屏；换备用机（Chrome + 独显） |
| 首屏超过 8 s | 提前打开浏览器标签预热，演示时只切标签 |
| 核显掉帧 | 把窗口降到 1600×900；关闭其他标签与投屏软件 |
| 投影分辨率不是 16:9 | 用浏览器窗口而非全屏，保持 16:9 内容区 |
| 语言/主题状态被上次演示改动 | 刷新页面，或按 `R` 后手动确认中/影棚 |
| 导览中途误点 | `Esc` 退出后重新 `T` 从第 1 步开始 |
