# Skyframe 787 项目说明书

> 波音 787-9 交互式结构图鉴 —— 把一架宽体客机拆成 113 个可点击部件，用程序化三维模型讲清楚「它为什么这样设计」。

| 项 | 内容 |

| 仓库 | <https://github.com/summit05427/skyframe-787> |

| 产物 | 单个自包含 `dist/index.html`，可离线双击打开 |

| 许可 | ISC（代码）；运行时依赖 three.js 为 MIT |

## 1. 项目定位

面向科普与参赛评审的三维图鉴：不做“模型展示”，而是把整机结构、材料、机构与操作逻辑组织成可交互的教学叙事。

三条主线：

1. **整机可拆解**：外观 → 透视 → 剖视 → 分解 → 材料，五种模式回答不同层级的问题。
2. **部件可讲解**：113 条部件条目，含中英文名称、说明、关键参数与「你知道吗」。
3. **机构可操作**：襟翼、副翼/升降舵/方向舵、平尾配平、减速板、起落架、反推、发动机、冲压空气涡轮、灯光与舷窗调光。

全部几何、涂装与动画由代码生成，仓库内没有任何外部模型或贴图资源。

## 2. 快速开始

环境要求：Node.js 22 及以上（CI 使用 Node 22）。

```bash
npm install
npm run dev      # 监听源码变化并重建 dist/index.html
npm run serve    # 本地预览 http://localhost:8787/
npm run build    # 生产构建（node build.mjs --min）
```

构建产物为 `dist/index.html`（约 1.05 MB，样式与脚本全部内联）。`dist/` 与 `node_modules/` 已被 `.gitignore` 忽略，首次运行需要先构建。

## 4. 功能说明

### 4.1 五种显示模式

| 模式 | 快捷键 | 说明 |
|---|---|---|
| 外观 | `1` | 真实涂装与外形，点击任意部件查看讲解 |
| 透视 | `2` | 蒙皮半透明，可直接看到并点选内部结构与系统 |
| 剖视 | `3` | 用剖切面切开蒙皮，滑块移动剖切位置，可切纵剖 / 俯剖 |
| 分解 | `4` | 按制造分段把机体分开，滑块控制分解程度 |
| 材料 | `5` | 按结构材料着色，并给出按重量的材料占比图例 |

### 4.2 面板与布局

- **顶栏**：中间为模式胶囊（当前模式用 2px 猩红指示线标记），右侧为工具区（导览、标注、尺寸、环境光照、复位、语言、帮助）。
- **左侧部件面板**：搜索 + 分组部件树；桌面端通顶显示，可一键折叠为边缘抓手。
- **右侧信息面板**：总览或选中部件详情（参数、体积/重量类数据、「你知道吗」、聚焦 / 单独显示）；可折叠。
- **底部参数面板**：飞行操纵 / 动画与灯光 / 显示三个标签页；顶部边缘有折叠抓手，收起后整块下滑，仅留抓手。
- **模式附加条**：剖视 / 分解 / 材料模式在模式胶囊下方出现对应的滑块或图例，外观与透视模式不显示任何附加条。

### 4.3 主题与语言

- **环境光照**：影棚（深色演播室光）/ 日光（蓝天 + 浅色地面），双段控件切换，3D 场景、环境贴图、雾与尺寸线颜色同步。
- **界面语言**：中 / EN 双段控件；语言优先级 `?lang=en` → `localStorage.skyframe.locale` → 默认 `zh`。切换时不重建三维模型，选中与导览状态保留。

### 4.4 交互与快捷键

| 操作 | 快捷键 / 手势 |
|---|---|
| 旋转 / 缩放 / 平移 | 左键拖动 / 滚轮、双指捏合 / 右键拖动、双指拖动 |
| 查看部件讲解 | 单击部件 |
| 取消选择 | `Esc` |
| 模式切换 | `1` – `5` |
| 起落架收放 | `G` |
| 襟翼放下一档 / 收回一档 | `F` / `Shift + F` |
| 减速板 | `B` |
| 发动机运转 / 停车 | `E` |
| 反推 | `V` |
| 标注 / 尺寸 | `L` / `D` |
| 导览开始或退出 | `T` |
| 导览上一步 / 下一步 | `←` / `→` |
| 复位视角 | `R` |
| 操作帮助 | `?` |

## 5. 技术架构

### 5.1 渲染与场景

- `src/scene/stage.js` 负责 `WebGLRenderer`、`PerspectiveCamera`、`OrbitControls`、程序化天穹着色器、PMREM 环境贴图、地面与网格。
- 后期使用 `EffectComposer`：`RenderPass` + 两层 `OutlinePass`（悬停白色 / 选中猩红）+ `OutputPass`。
- 布局遮挡处理：左右面板会占据画面两侧，`layoutView()` 通过 `camera.setViewOffset()` 把投影中心移到未被遮挡区域的中央，并按可用宽高比决定机位远近。

### 5.2 状态与拾取

- 全局状态集中在 `main.js` 的 `S` 对象（当前模式、图层、剖切、分解、标注、选中、导览进度、操纵值等）。
- 部件通过 `Registry` 反查：每个 mesh 在构建时登记所属部件 id，拾取时用 `userData.pid` 命中讲解数据。
- 选中 / 悬停高亮走 `OutlinePass`，不对每个部件单独生成描边网格。

### 5.3 构建

- `build.mjs` 用 esbuild 打包 `src/index.html` 中的入口，CSS 与脚本内联，输出单文件 `dist/index.html`。
- CI（`.github/workflows/pages.yml`）：推送 `main` → `npm ci` → `node build.mjs --min` → 发布 `dist/` 到 GitHub Pages。

### 5.4 国际化

- 词典按语义键组织：`src/i18n/ui.js`（界面文案）、`meta.js`（名称/单位等元数据）、`parts-1~3.js`（113 条讲解）。
- `t(key, vars)` 取词并做插值，`setLocale` / `onLocaleChange` 负责运行时切换与重渲染。
- 不引入第三方 i18n 框架，避免额外请求与包体膨胀。

## 6. UI 设计规范

### 6.1 色彩（暗黑高级 + 猩红强调）

| Token | 值 | 用途 |
|---|---|---|
| `--ink` | `#07070A` | 页面最深底色 |
| `--bg` | `rgba(17,17,21,.86)` | 面板玻璃底 |
| `--bg2 / --bg3` | `rgba(255,255,255,.05 / .10)` | 一级 / 二级悬停与分段底 |
| `--line` | `rgba(255,255,255,.11)` | 中性发丝描边 |
| `--tx / --tx2 / --tx3` | `#F3F0ED / #A6A1A1 / #6E6969` | 三级文字 |
| `--acc` | `#C1121F` | 猩红实心：主按钮、指示线、滑块进度 |
| `--acc-hover` | `#A50F1A` | 主按钮悬停 |
| `--acc-text` | `#FF6B6B` | 暗底上的红字 / 图标（保证可读） |
| `--acc-soft` | `rgba(193,18,31,.14)` | 低透明度红底 |
| `--acc-line` | `rgba(193,18,31,.55)` | 红色描边 |
| `--on-acc` | `#FFFFFF` | 猩红底上的白字 |

红色遵循 80/20：仅用于主操作、当前状态指示线、滑块已滑过段与拇指描边、列表选中竖条、3D 热点与极值数值；其余一律中性灰。

### 6.2 组件约定

- **选中态**：模式 / 标签页 = 纯白文字 + 2px 猩红底边；列表项 = 深灰底 + 左侧 3px 猩红竖条 + 白字；开关 = 浅灰底 + 白字 + 猩红状态点。
- **滑块**：未滑过轨道 `#333`，已滑过段 3px 猩红，拇指为白色圆点 + 猩红描边 + 辉光，数值默认 `#D6D6D6`，到达最大值才转红。
- **折叠**：左右面板与底部面板共用 `.panel-handle` 边缘抓手，折叠后抓手贴边，图标翻转，面板滑出。
- **字体**：`Bahnschrift / DIN Alternate / PingFang SC / 微软雅黑`；数字、代号与状态值使用等宽栈（`Cascadia Mono / SF Mono / Consolas`）。

### 6.3 响应式断点

| 断点 | 行为 |
|---|---|
| `≤1340px` | 收起标注 / 尺寸 / 复位等次要工具，避免与居中模式胶囊重叠 |
| `≤1180px` | 顶栏切回 flex 流式布局；左侧面板改为抽屉，由左上角按钮开合 |
| `≤900px` | 压缩模式胶囊字号与内边距 |
| `≤820px` | 隐藏主题切换与次要工具；信息面板改为底部浮层；底部参数面板默认收起 |

## 7. 内容维护

### 7.1 新增部件

1. 在 `src/aircraft/` 对应模块中构建几何，并通过 `Registry` 登记部件 id。
2. 在 `src/data/parts.js` 增加条目（中英文名、分组、说明、关键数据、「你知道吗」、标注类型、推荐观察模式）。
3. 在 `src/i18n/parts-*.js` 补充英文文案。

### 7.2 新增导览步骤

在 `src/data/tour.js` 追加步骤，字段包含标题、正文、镜头机位、模式与选中目标；`main.js` 会自动生成进度点与上一步/下一步。

### 7.3 新增界面文案

统一加在 `src/i18n/ui.js` 的 `zh` 与 `en` 两份词典中，业务代码只通过 `t('key')` 取词，禁止硬编码中英文。
