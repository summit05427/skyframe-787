# Skyframe 787 · 运行与构建说明

> 目标：任何人拿到仓库或离线包，都能一次跑对；录屏人员不会因为入口、构建、端口、`file://`、首屏等待或画质选错而返工。

---

## 1. 必须写死的六件事

| 项 | 结论 |
|---|---|
| **准确入口** | `boeing/dist/index.html`（**不是** `boeing/index.html`，也**不是** `boeing/src/index.html`） |
| **是否需要先 build** | **需要**。`dist/` 被 `.gitignore` 忽略，首次必须 `npm install && npm run build` |
| **本地端口** | `http://localhost:8787/`（`scripts/serve.mjs` 默认 8787，可用参数或 `PORT` 覆盖） |
| **是否支持 `file://`** | **支持**。`dist/index.html` 样式与脚本全内联，双击即可离线运行（已实测） |
| **首屏加载耗时** | 本机实测 **3.5 s** 完成启动（1920×1080）/ **3.55 s**（1600×900）/ `file://` **3.32 s**；应用就绪约 **3.0 s**；录制前等 **5 s** |
| **录制画质** | 项目**只有唯一固定画质档**（无高/低切换）：像素比 ≤2、4096² 阴影。录制用 **1920×1080 / 30fps / 系统缩放 100%**；核显若低于 28 FPS，改 **1600×900** 采集 |

## 2. 目录与产物

```text
boeing/
├─ src/                    源码（不可直接打开）
│  ├─ index.html           模板：含 /*__CSS__*/ 与 /*__JS__*/ 占位
│  ├─ main.js              入口
│  └─ styles.css
├─ dist/
│  └─ index.html           唯一运行产物（构建生成，约 1064 KB）
├─ build.mjs               esbuild 单文件内联
├─ scripts/
│  ├─ serve.mjs            零依赖静态服务器
│  ├─ fps.mjs              各模式帧率自检（依赖 ego-browser 环境）
│  ├─ ui-test.mjs          指针交互自检（同上）
│  ├─ leak.js / q.mjs / shot.sh  开发期辅助
├─ package.json            仅 three + esbuild 两个 devDependencies
└─ .github/workflows/pages.yml  Pages 自动部署
```

运行时会加载的文件只有 `dist/index.html` 一个；没有字体、贴图、模型或 CDN 请求。

## 3. 三种运行方式

### 3.1 直接双击（推荐给评审 / 离线演示）

1. 先确认 `dist/index.html` 存在且为最新（改动源码后要重新构建）；
2. 双击打开，地址栏为 `file:///.../boeing/dist/index.html`；
3. 等待约 3.3–3.6 s 进入场景。

> Chrome / Edge 实测 `file://` 正常。`file://` 下 `localStorage` 在隐私模式可能受限，语言记忆会失效，但主功能不受影响；需要英文时用 `?lang=en`。

### 3.2 本地服务器（推荐给开发 / 录屏）

```powershell
cd boeing
npm install      # 仅首次
npm run build
npm run serve    # 或 node scripts/serve.mjs
```

- 地址：`http://localhost:8787/`
- 端口覆盖：

```powershell
node scripts/serve.mjs 8788
# 或
$env:PORT=8788; npm run serve
```

- 服务器根目录固定为 `dist`，返回 `Cache-Control: no-cache`，改完构建后刷新即可。

### 3.3 在线体验

<https://summit05427.github.io/skyframe-787/>

由 GitHub Actions 从 `main` 自动部署，单文件产物不需要 base 路径配置。

## 4. 什么时候必须重新构建

| 改动 | 是否需要 `npm run build` |
|---|---|
| `src/main.js`、`src/aircraft/**`、`src/core/**`、`src/data/**`、`src/i18n/**`、`src/scene/**` | **是** |
| `src/styles.css`、`src/index.html` | **是**（二者在构建时内联进产物） |
| 只改 `docs/**`、`README.md` | 否 |

开发时用监听模式：

```powershell
npm run dev      # node build.mjs --watch
```

构建命令与产物：

```powershell
npm run build    # 等价于 node build.mjs --min
# 入口：src/main.js
# 输出：dist/index.html（CSS/JS 全内联，target es2022）
```

构建耗时：本机 **约 0.96 s**；产物 **1,089,894 字节（约 1064 KB）**。

> **不要手工编辑 `dist/index.html`**，下次构建会被覆盖。

## 5. 首屏加载耗时

本机实测（Windows 11、Chrome 158.0.8127.89、Intel UHD、DPR 1、本地服务器 / `file://`）：

| 指标 | 1920×1080 | 1600×900 | `file://` 1600×900 |
|---|---|---|---|
| DOMContentLoaded | 0.80 s | 0.77 s | 0.77 s |
| load 事件 | 3.03 s | 3.07 s | 2.86 s |
| 应用就绪（`window.__app`） | 约 3.0 s | 约 3.1 s | 约 2.9 s |
| 启动遮罩完全移除 | **3.50 s** | **3.55 s** | **3.32 s** |

说明：

- 时间主要花在程序化生成整机几何、材质、标注与拾取系统，不是网络等待。
- 在线访问还需叠加网络时间；低端设备可能 6–10 s。
- **录制建议**：打开后等 **5 s** 再开始录，避免把启动遮罩与首帧编译录进正片。

## 6. 帧率与录制画质

项目**没有画质切换按钮**，渲染参数固定：

- `renderer.setPixelRatio(min(devicePixelRatio, 2))`
- 阴影 `PCFShadowMap`、4096×4096
- 后期 4× MSAA、两层 OutlinePass、ACES 色调映射

实测帧率（Chrome 158 / Intel UHD / DPR 1）：

| 模式 | 1600×900 | 1920×1080 |
|---|---|---|
| 外观 | 41.1 | 31.0 |
| 透视 | 36.6 | 28.4 |
| 剖视 | 33.4 | 26.0 |
| 分解 | 42.8 | 33.5 |
| 材料 | 40.2 | 32.8 |

录制口径：

| 项 | 建议 |
|---|---|
| 分辨率 | 1920×1080 |
| 帧率 | 30fps（平台要求 H.264 / 30fps） |
| 系统缩放 | 100%，避免 DPR 2 让渲染像素翻倍 |
| 画质 | 唯一固定档；核显低于 28 FPS 时改 1600×900 采集后放大 |
| 浏览器 | Chrome / Edge，关闭其他标签页与录屏外的硬件加速冲突软件 |
| 首屏 | 等 5 s |
| 镜头 | 每次相机飞行后等 1.8–2.5 s |

> 若评审机器是核显且要求严格 30fps，优先保证流畅：用 1600×900 录制，或在剖视等最重镜头缩短停留时间。

## 7. 本次录制踩过的三个坑（逐项核对）

| 项目 | 正确入口 / 事实 | 原因与规避 |
|---|---|---|
| **`boeing`** | **必须用 `boeing/dist/index.html`** | 根目录没有 `index.html`；`src/index.html` 是带 `/*__CSS__*/`、`/*__JS__*/` 占位符的模板，直接打开是空壳。录制前先 `npm run build`，确认 `dist/index.html` 的修改时间是最新。 |
| **`sports-car-simulator`** | **只有 `docs/index.html` 可用；1080p 约 8 FPS** | 根目录 `index.html` 是 Vite 开发入口，不是最终产物。该作品 1080p 性能不足，录制应降低分辨率/画质，或直接使用仓库 `shots/` 现成素材，避免现场卡顿。 |
| **`china-space-station`** | 入口 `china-space-station/index.html`；**旧版本折叠面板后画布不会自动重算** | 旧版缺少 `ResizeObserver`，折叠左右栏后 canvas 缓冲区未更新，画面被拉伸或留黑边；当前 `main` 已由 `SceneManager` 监听 `#canvas-container` 自动 `resize()`。若仍遇到，强刷 `Ctrl+F5` 或重新构建。 |

补充说明（本项目）：

- `boeing` 的画布始终铺满窗口，折叠面板只改变 `camera.setViewOffset()` 的投影中心，**不需要**重算 canvas 尺寸，因此不会出现空间站旧版那种拉伸；窗口 resize 时 `stage.js` 会同步 `renderer/composer` 尺寸。
- 三个项目录制前统一检查：**入口路径、是否需要构建、端口、`file://`、首屏等待、画质档**，六项逐项打勾。

## 8. 测试与自检

`scripts/` 下的脚本依赖外部 `ego-browser` / `taskSpace` 环境，**不参与 CI**：

```powershell
# 各模式帧率与渲染统计
ego-browser nodejs < scripts/fps.mjs

# 悬停 → 点击 → 控制台页签 → 尺寸 → 日光 → 键盘 → 搜索
ego-browser nodejs < scripts/ui-test.mjs
```

浏览器内调试出口：`window.__app`（`stage`、`aircraft`、`S`、`setMode`、`select`、`tourGo` 等），可在控制台直接调用。

当前**没有** ESLint、Prettier、单元测试或 Playwright 冒烟；回归依赖人工。新增功能后至少手动走一遍：

- 五种模式切换与附加条；
- 剖视/分解滑块；
- 部件树搜索与点选；
- 三块面板折叠与相机重新取景；
- 中英切换、主题切换；
- 导览开始/上一步/下一步/退出；
- 控制台 0 报错。

## 9. 部署与回滚

- 工作流：`.github/workflows/pages.yml`
- 触发：推送 `main` 或手动 `workflow_dispatch`
- 步骤：`npm ci` → `node build.mjs --min` → 上传 `dist/` → 部署 Pages
- Pages Source：**GitHub Actions**（`build_type=workflow`）

```powershell
git add <files>
git commit -m "docs(docs): 补齐交付文档并补录实测数据"
git push origin main
gh run watch $(gh run list --workflow=pages.yml -L 1 --json databaseId --jq '.[0].databaseId') --exit-status
```

回滚：`git revert <commit> && git push`，Actions 会重新部署上一版，不需要改 Pages 设置。

验证：根路径 200、页面有业务内容、静态资源 200、控制台无报错。

## 11. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 打开是空白页 | 打开了 `src/index.html` 或根目录不存在的 `index.html` | 改用 `dist/index.html` |
| 启动遮罩一直不消失 | WebGL2 不可用 / 硬件加速关闭 / 旧构建 | 换 Chrome/Edge，开启硬件加速；重新 `npm run build` |
| `ERR_CONNECTION_REFUSED` | 服务器未启动或端口被占 | `npm run serve`；或 `node scripts/serve.mjs 8788` |
| 改了源码页面没变 | 没重新构建，或浏览器缓存旧文件 | `npm run build` 后 `Ctrl+F5` |
| 线上是旧版 | 未推送或 Actions 未完成 | `git push origin main`，等 Actions 完成，强刷 |
| 中文/英文切换无效 | 旧构建或 `localStorage` 被限制 | 强刷；用 `?lang=en` |
| 核显掉帧 | 1080p + DPR 2 + 剖视 | 降低窗口分辨率、系统缩放改 100% |
| 手机端控制台不见了 | ≤820 默认收起 | 点底部横条抓手展开 |
| 折叠面板后构图偏移 | 相机投影中心随可用区域重算，属预期 | 按 `R` 复位，或重新展开面板 |
