# Skyframe 787 · 页面与模块说明

> 面向维护者与二次开发：页面由哪些区域组成、每个源码文件负责什么、状态如何流动。
> 入口：`boeing/dist/index.html`（由 `src/index.html` + `src/main.js` + `src/styles.css` 构建）。

---

## 1. 页面结构

`src/index.html` 只有 4 个业务容器 + 1 个启动遮罩：

```html
<body data-theme="studio">
  <div id="stage"></div>    <!-- three.js 画布挂载点 -->
  <div id="labels"></div>   <!-- 三维热点标签与尺寸标签（DOM 覆盖层） -->
  <div id="ui"></div>       <!-- 全部界面，由 main.js 注入 innerHTML -->
  <div id="boot">…</div>    <!-- 启动遮罩，初始化完成后移除 -->
</body>
```

`main.js` 启动时向 `#ui` 写入顶栏、三块面板、导览卡、提示、Toast 与帮助层。因此**界面 DOM 不在 HTML 中静态存在**，改 UI 结构要改 `main.js` 的模板字符串。

### 1.1 区域与 DOM

| 区域 | 根节点 | 关键子节点 | 说明 |
|---|---|---|---|
| 3D 画布 | `#stage` | `canvas` | 全屏固定，`inset: 0` |
| 标注层 | `#labels` | `.hs`、`.dimlab` | `pointer-events: none`，热点自身可点 |
| 顶栏 | `#top` | `#modes`、`#tools`、`#btn-list` | 中间模式胶囊，右侧工具 |
| 模式附加条 | `#modebar` | `[data-axis]`、`#cutk`、`#expk`、`.legend` | 仅剖视/分解/材料显示 |
| 左部件面板 | `#left` | `#q`、`#tree` | 搜索 + 8 组部件树 |
| 右信息面板 | `#right` | `#info` | 总览或部件详情 |
| 底部控制台 | `#console` | `.tabs`、`#pane` | 三个标签页 |
| 导览卡 | `#tourcard` | 步骤号、正文、`.dots`、上一/下一步 | 导览时显示 |
| 折叠抓手 | `#tgl-left`、`#tgl-right`、`#tgl-console` | — | 常驻边缘 |
| 浮层 | `#tip`、`#toast`、`#help` | — | 悬停提示、瞬时提示、帮助 |

### 1.2 布局策略

- 画布与标注层铺满窗口；面板全部为绝对定位浮层，**不挤压画布**。
- 面板遮挡画面两侧，因此 `layoutView()` 用 `camera.setViewOffset()` 把投影中心移到可见区域中央。
- 折叠面板只改投影偏移与 CSS 位移，不调用 `renderer.setSize()`；画布尺寸始终等于窗口，所以不会出现空间站项目那种「折叠后画布拉伸」问题。
- 窗口 `resize` 同时触发 `stage.js` 的 `resize()`（相机宽高比、渲染器、后期缓冲）与 `main.js` 的 `layoutView()` / `syncConsole()`。

## 3. 状态模型

### 3.1 全局状态 `S`

| 字段 | 默认 | 含义 |
|---|---|---|
| `mode` | `ext` | 当前显示模式 |
| `layers` | 5 层全 `true` | `skin/struct/cabin/sys/gear` |
| `cutAxis` | `z` | 纵剖 / 俯剖 |
| `cutK` | `0` | 当前剖切位置 |
| `explodeK` | `1` | 分解程度 0–1 |
| `labels` | `true` | 三维热点开关 |
| `dims` | `false` | 尺寸线开关 |
| `selected` | `null` | 选中部件 id |
| `hovered` | `null` | 悬停部件 id |
| `isolate` | `false` | 单独显示 |
| `tour` | `-1` | 导览步号，-1 表示未开始 |
| `flight` | `false` | 飞行状态（机翼上挠、收起落架、隐藏地面） |
| `tab` | `fly` | 控制台标签页 |
| `windowDim` | `0.8` | 舷窗调光 0–1 |

### 3.2 机构目标值 `aircraft.tgt`

`flaps`、`speedbrake`、`roll`、`pitch`、`yaw`、`trim`、`gear`、`reverser`、`n1`、`rat`、`flex`、`explode`。
每帧按 `rate` 从 `cur` 向 `tgt` 收敛，`update(dt)` 后调用 `apply()` 写入几何。变化速率见 [交互控件索引.md](交互控件索引.md) 第 8 节。

### 3.3 DOM 状态类

| 类 | 挂在 | 作用 |
|---|---|---|
| `no-left` / `no-right` | `body` | 左右面板折叠 |
| `console-min` | `body` | 底部控制台收起 |
| `touring` | `body` | 导览中，隐藏侧栏与抓手 |
| `has-sel` | `body` | 有选中部件（移动端显示信息浮层） |
| `show-left` | `body` | ≤1180 时打开左抽屉 |
| `no-modebar` | `body` | 无模式附加条时上移 Toast |
| `data-theme` | `body` | `studio` / `day`，供 CSS 与场景使用 |
| `data-locale` | `body` | `zh` / `en`，调整英文排版 |

## 4. 关键数据流

### 4.1 几何 → 可拾取部件

```text
aircraft/*.js 构建 THREE.Mesh
        │
        ├─ Registry.reg(id, obj, { layer, mc, side })
        │        └─ 写入 userData.part / layer / mc
        │
        └─ main.js 遍历 root，把 Registry.partOf(mesh) 结果写入 userData.pid
                 │
                 └─ pick() 命中 userData.pid → PARTS[id] → select(id) → 信息卡
```

- `Registry.parts` 是 `Map<id, { id, objects[] }>`；`objectsOf(id)` 返回该部件的所有根对象。
- 一个讲解条目可对应多个网格（如 8 扇舱门、多根长桁），信息卡会显示「模型中共 N 处」。

### 4.2 模式切换

```text
setMode(mode)
  ├─ 还原材料模式临时材质（mat0）
  ├─ 清空蒙皮剪裁面 / 透明 / 双面状态
  ├─ 重置透视 uniform（U.xray = 0）与分解目标
  ├─ 按模式设置：透视透明、剖切平面、分解目标、材料替换
  ├─ 调整描边「被遮挡边」亮度（透视/剖视 100%，其余 12%）
  ├─ refreshVis() + renderModeBar()
  └─ 分解模式且非导览 → goHome()
```

### 4.3 选中

```text
select(id, { focus, auto })
  ├─ 清空上一次密集件提亮
  ├─ 设置 OutlinePass.selectedObjects
  ├─ auto：自动打开所属图层；外观模式选中内部件则切透视
  ├─ refreshVis() + renderInfo()
  ├─ 同步部件树高亮并滚动到可见
  ├─ focus：相机飞向包围球
  └─ body.has-sel 切换
```

### 4.4 导览

```text
tourGo(i)
  ├─ body.touring + console-min
  ├─ 清空循环计时器，resetControls()
  ├─ 应用步骤 set / layers / cut / mode
  ├─ setMode() + select()
  ├─ layoutView() + flyTo(fitCam(cam), 1.7s)
  ├─ 渲染控制台与导览卡
  └─ 若 loop：setInterval 在两个状态间往返（如起落架每 8s）
```

## 5. 渲染管线

```text
WebGLRenderer（ACES、PCF 阴影、localClipping）
  └─ EffectComposer
       ├─ RenderPass（sky + 整机 + 地面）
       ├─ OutlinePass（悬停：白色，强度 2.6）
       ├─ OutlinePass（选中：猩红 #FF5A6A，强度 4.5）
       └─ OutputPass
```

- 每帧：相机飞行插值 → `controls.update()` → 透视 uniform 收敛 → 相机 near 自适应 → `aircraft.update(dt)` → 拾取队列 → `stage.render()` → `updateLabels()`。
- 相机 near 随视距调整（`clamp(d·0.02, 0.12, 3)`），避免贴近部件时穿模。
- `dt` 上限 0.05s，防止切后台后机构跳变；相机飞行使用真实时间，切后台不受影响。

## 6. 国际化结构

| 文件 | 内容 |
|---|---|
| `i18n/ui.js` | 界面文案：按钮、标签、状态、帮助、Toast、尺寸名 |
| `i18n/meta.js` | 分组名、规格表、材料分类名、占比说明、导览英文 |
| `i18n/parts-1~3.js` | 113 条部件的英文 `d/f/t` |
| `i18n/index.js` | `detectLocale`、`t`、`setLocale`、`onLocaleChange`、`partName` 等 |

切换流程：`setLocale` → 覆盖 `PARTS` 的 `d/f/t` 与 `TOUR` 文案 → 写 `localStorage` 与 URL → 通知订阅者重渲染界面与标签 → 不重建几何。

新增文案必须 zh/en 成对，否则 `t()` 回退到中文键值。

## 7. 构建与产物

```text
src/index.html  ──┐
src/styles.css  ──┼─ build.mjs（esbuild）─→ dist/index.html
src/main.js     ──┘        内联 CSS/JS
```

- esbuild 配置：`bundle: true`、`format: 'esm'`、`target: 'es2022'`、`write: false`、`--min` 时压缩。
- 内联插件在 `onEnd` 读取产物 JS 与 CSS，替换模板占位符，并把 `</script` 转义为 `<\/script`。
- 产物只有一个 HTML，无外部资源；运行时零请求。
