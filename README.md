# Skyframe 787 · 波音 787-9 结构图鉴

把一架波音 787-9 拆成 113 个可点击部件，用程序化三维模型讲清楚「它为什么这样设计」。

- 在线体验：<https://summit05427.github.io/skyframe-787/>
- 默认中文，顶栏 `EN` 切换英文；也可用 `?lang=en` 直接打开英文版
- 单个 HTML 产物，可离线双击打开，不请求任何后端接口

## 功能

- **五种显示模式**：外观、透视、剖视、爆炸、材料。透视与剖视下可直接点选被蒙皮遮住的内部件。
- **16 步导览**：从整机尺度、复合材料比例、总装分段，到机翼增升、发动机、反推、起落架、机身骨架、客舱、多电架构、燃油与尾翼。
- **113 条部件讲解**：每条包含中英文名称、说明、关键参数与「你知道吗」。
- **飞行操纵**：襟翼十档、副翼/升降舵/方向舵、平尾配平、减速板、起落架收放、反推、发动机、冲压空气涡轮、灯光与舷窗调光。
- **尺寸标注与部件热点**：机长、翼展、机高、主轮距、前主轮距、发动机距中线。
- **中英双语**：界面、部件讲解、导览、规格表、材料图例全部双语，默认中文。
- **响应式**：桌面三栏、窄屏抽屉式部件列表、移动端底部面板。

## 快速开始

要求 Node.js 22 或更高版本（CI 使用 Node 22）。

```bash
npm install
npm run dev      # 监听源码变化并重建 dist/index.html
npm run serve    # 打开 http://localhost:8787/
```

生产构建：

```bash
npm run build    # 等价于 node build.mjs --min
```

构建产物是 `dist/index.html`，样式与脚本已全部内联，可直接双击离线打开。`dist/` 与 `node_modules/` 已在 `.gitignore` 中忽略，首次运行需要先构建。

## 中英双语

- 默认语言为中文；顶栏 `EN / 中` 按钮即时切换，不重建三维模型、不丢失当前选中与导览状态。
- 语言优先级：`?lang=en` → `localStorage.skyframe.locale` → 默认 `zh`。
- 覆盖范围：界面按钮与提示、113 条部件讲解、16 步导览、规格表、材料分类与占比图例。
- 实现位于 `src/i18n/`，不引入第三方 i18n 框架，避免额外请求与包体膨胀。

## 项目结构

```text
src/
├─ main.js              应用入口：UI、状态、拾取、标注、导览、主循环
├─ index.html           页面骨架与构建注入标记
├─ styles.css           全部样式与响应式规则
├─ aircraft/            几何与机构：机身、机翼、发动机、尾翼、起落架、结构、客舱、系统
├─ core/                几何工具与材质库
├─ data/                113 条部件讲解、16 步导览脚本
├─ i18n/                中英文词典与内容覆盖层
└─ scene/stage.js       渲染器、相机、环境光、后期描边
scripts/                开发期自检脚本与零依赖静态服务器
build.mjs               esbuild 单文件内联构建
```

## 部署

推送到 `main` 分支后，GitHub Actions 会执行 `npm ci`、`node build.mjs --min`，并把 `dist/` 发布到 GitHub Pages：

- 工作流：`.github/workflows/pages.yml`
- 仓库 Pages 的 Source 需设为 **GitHub Actions**

本地可先用 `npm run build && npm run serve` 验证产物。

## 浏览器要求

需要支持 WebGL2 的现代浏览器（Chrome / Edge / Safari / Firefox 近两年版本）。移动端可使用单指旋转、双指缩放与拖动。

## 开发脚本

- `scripts/serve.mjs`：零依赖静态服务器（`npm run serve`）。
- `scripts/fps.mjs`、`ui-test.mjs`、`leak.js`、`q.mjs`、`shot.sh`：人工自检脚本，依赖外部 `ego-browser` / `taskSpace` 环境，不属于 CI 流程。
